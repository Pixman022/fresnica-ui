# Asset provenance checklist

This checklist separates project-owned assets from third-party dependencies. It
does not grant rights by itself; the project owner must confirm the source and
redistribution permission before a public release.

| --- | --- | --- | --- |
| Fresnica brand marks | `demo/img/fresnica/fresnica-logo*.png`, `fresnica-app-icon.png` | README, demo shell and wallet examples | Original project assets; confirmed for public distribution |

| Banner artwork | `banner01.webp`–`banner04.webp` | Image and Carousel examples | Original project assets; confirmed for public distribution |
| Fonts | `@fontsource/roboto`, `@fontsource/noto-sans-sc` | Runtime typography | OFL 1.1; recorded in `THIRD_PARTY_NOTICES.md` |
| Interface icons | `lucide-react` | Component and demo icons | ISC; recorded in `THIRD_PARTY_NOTICES.md` |

The project owner has confirmed that the listed Fresnica images are original
project assets and may be publicly distributed. Revisit this status if an asset
is replaced or if an external source is introduced.
