# Fresnica 设计规范

本规范是当前设计事实来源。Fresnica 视觉仅作为参考资料，不得覆盖 Fresnica 已确认的设计决策。

## 视觉原则

1. **产品性格**：现代金融科技与加密资产钱包；专业、精确，并保留柔和圆角。
2. **主色**：Light `#00A875`；Dark `#00CA8A`。推荐 hover 色为 Light `#00CA8A`、Dark `#32DFA4`；active 色为 Light `#008F65`、Dark `#00A875`。品牌绿只用于品牌识别、区域主操作和必要选中状态，不作为普通信息的默认颜色。
3. **辅助色**：控制为四种语义色——科技协议紫（浅色 `#6956C8`、深色 `#B8A9FF`）、网络信息蓝（浅色 `#356AE6`、深色 `#8EAEFF`）、Swap/流动性橙（浅色 `#C96A16`、深色 `#FFB86B`）和待处理/注意黄（浅色 `#A87500`、深色 `#F6C65B`）。除非出现新的产品状态，否则不增加色相。
4. **表面层级**：使用语义化 surface 色阶和清晰的 1px 描边；组件及浮层均不使用投影，层级通过表面对比、边框与遮罩表达。
5. **圆角**：控件使用 8–16px，卡片和浮层使用 16–24px；完整胶囊仅用于紧凑 Tag、Switch 和分段控件。
6. **字体**：Roboto、`Noto Sans SC`，最后使用系统兜底；正文最低 400，标签和操作通常为 600–700。
7. **动效**：0.15–0.35s，缓动 `cubic-bezier(0.4, 0, 0.2, 1)`，并提供 reduced-motion 兼容。
8. **焦点**：所有交互元素统一使用 `--Fresnica-focus-color`，不使用无关装饰色作为焦点环。

## 移动端字体基线

使用 Roboto（拉丁字母与数字）和 `Noto Sans SC`（中文），再按现有系统字体兜底。移动端基线检查 320px、360px、390–393px 和 430px；768px 与桌面宽度遵循平台适配层规则：

| 角色 | 字号 / 行高 | 字重 | 使用场景 |
| --- | --- | --- | --- |
| 页面标题 | 20 / 26px | 700 | 顶部栏和页面标题 |
| 区块标题 | 16 / 22px | 700 | 卡片和底部弹层标题 |
| 正文 | 14 / 20px | 400 | 主要内容和表单值 |
| 标签 | 12 / 16px | 600 | 字段标签、元数据、徽标 |
| 主金额 | 28–32 / 36–40px | 700 | 余额和交易金额 |
| 按钮文字 | 15 / 20px | 600 | 主按钮和 inverse 操作 |

余额、汇率、手续费和交易 ID 使用等宽数字（tabular numerals）。主要正文不低于 14px；单行文本建议控制在约 45–70 个字符以内。

## 网络范围

当前产品只支持 Stellar。网络名称、节点和示例统一使用 Stellar Mainnet、Stellar Testnet 或 Stellar Horizon；在产品范围变更前，不加入 Ethereum、Solana、Polygon 或其他链的专属 UI。

## 前景对比度硬规则

- 所有绿色实心操作控件和选中控件必须使用纯白文字：`#FFFFFF`。
- 包括主按钮、加载中的主按钮、选中 Tabs、当前 Pagination、选中的 DatePicker/TimePicker 项，以及 Modal 主操作。
- 即使在深色模式下，也禁止绿色实心控件使用深色文字。
- 紫色实心控件的前景必须满足 WCAG AA；浅紫容器使用 `--Fresnica-accent-purple-color-bg` 与 `--Fresnica-accent-purple-color`。
- 禁用态可以降低透明度，但文字仍须可辨识。

## 绿色强调层级

- 单个页面或操作区域最多保留一个大面积实心主色重点。钱包首页已批准的 Send / Swap / Receive 快捷操作组是明确的产品例外。
- 普通图标、资产符号占位、复制、Max/All、方向切换、帮助文字和预计数值使用中性表面及文字 Token。
- 底部导航当前项使用主绿色图标和文字，背景保持透明，不增加绿色选中容器。
- 品牌主色、成功和上涨保持独立。交易完成或节点在线使用成功 Token；资产正向变化使用上涨 Token；不能因为三者都呈绿色就改用品牌 Token。
- 协议身份可以使用协议紫，网络身份可以使用网络蓝。这些辅助色必须表达含义，不能作为随机装饰。
- 焦点可以使用焦点 Token，但不能让中性控件在非焦点状态持续显示为主绿色控件。

## 组件规则

- **Button**：主按钮为绿色背景配白色文字，并只用于区域主操作；default/dashed 使用中性表面。复制、Max/All、方向切换等次要操作保持中性；`inverse` 仅用于 Swap 等少数需要在主题间反转黑白对比度的核心操作。
- **Tabs**：选中项为绿色背景配白色文字；未选中项使用次级文字色。
- **Card**：使用语义表面和细边框；钱包流程禁止游戏装饰花纹。
- **Input 与 Select**：默认触控高度 48px，中性表面，清晰绿色焦点环。
- **Modal 与 Drawer**：使用常规金融科技圆角表面，维持焦点捕获和明确遮罩层级。
- **反馈状态**：品牌、成功、交易失败、上涨、下跌、警告、高风险和协议分别使用独立语义 Token，即使色相接近也不能合并。输入校验错误使用 `error`，不使用 `failure`。
- **数据展示**：保持紧凑密度、等宽数字、横向溢出和清晰行状态。

## Fresnica 正式界面禁用项

- 自然主题插画、场景化装饰、不规则 blob、趣味光标或其他游戏化表现。
- 羊皮纸背景、游戏式厚阴影或装饰性条纹 hover。
- 深色表面上的纯黑文字或低对比度灰色文字。
- 已存在 Fresnica 语义 Token 时继续硬编码颜色。
- 非 Lucide 的界面图标；已批准的 Fresnica Logo 与应用图标品牌资源除外。

## 评审清单

- Light 与 Dark 主题均正确渲染。
- 页面没有把普通图标、元数据、预计数值或次要操作显示为品牌绿。
- 大面积主绿色强调限制在一个操作区域内；钱包首页快捷操作组除外。
- 绿色实心控件在默认、hover、active、loading 状态下均为白色文字。
- 键盘焦点清晰且顺序合理。
- 触控目标至少 40px，主要操作优先 48px。
- 文字和控件满足 WCAG AA 对比度。
- 组件使用语义 Token，并保持已记录的 API 行为。
