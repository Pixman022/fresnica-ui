# Demo 站点

Demo 用于展示组件库与 Fresnica Stellar 钱包流程，只使用语义 CSS 变量，不使用装饰背景图片。

## 布局

- 根节点：`100dvh` 全高 Flex 布局，使用中性背景与轻微主色径向高光。
- 桌面 Sidebar：宽 268px，外边距 12px，圆角 16px，使用语义边框且不使用阴影。
- 主内容区：自适应宽度、独立滚动、内边距 `32px 40px`。
- 激活菜单项：主色背景与 `--Fresnica-on-primary-color`；非激活项使用次级文字色。
- 菜单项最小高度 44px，可随换行标签自适应高度，圆角 12px，hover 使用克制的主色容器色。

## 移动端

- 断点沿用 `useIsMobile`；固定顶栏高 52px，使用带模糊的语义表面。
- 主内容区左右内边距 16px、顶部内边距 68px。
- 导航抽屉宽 240px，配标准深色遮罩。
- 导航控件使用 Lucide 图标并提供无障碍标签。
- Layout 页面提供仅用于 Demo 的屏幕宽度切换器，可检查 `320px`、`360px`、`393px`、`430px`、`768px` 和桌面宽度下的组件组合。

## 首页

- Hero 只使用已批准的 Fresnica Logo 与应用图标。
- 字体为 Roboto，中文回退为 `Noto Sans SC`，移动字号遵循设计规范。
- 特性与组件卡片使用语义表面、边框、圆角与克制的悬停抬升动效。
- 示例内容围绕 Stellar 资产、转账、兑换、网络状态与交易签名。
- 主题示例展示浅色主色 `#00A875`、深色主色 `#00CA8A`，只使用 `--Fresnica-*` 变量。

## 钱包页面

以下路由需在亮/暗主题和移动宽度下完成视觉检查：首页、兑换、转账、活动、设置、交易详情、资产详情、网络节点、dApp 探索与扫描。

- `WalletDemoShell` 是钱包路由唯一的预览契约：宽 390px、高 844px，使用主题画布，内部可纵向滚动但隐藏可视滚动条，并隐藏横向溢出。它是移动端大屏示例，不是跨平台布局基线。
- 响应式验收预设为 320px、360px、390–393px、430px、768px 和实际桌面宽度。钱包外壳继续固定尺寸用于产品预览，响应式行为单独验收。
- 画布内的钱包控件以现有的 `--Fresnica-height-base` 作为最小触控尺寸；原本更大的控件继续保留其设计尺寸。
- 该外壳通过 React Context 强制钱包组合使用移动端布局；在预览框中渲染时，钱包 Demo 不得继续根据桌面浏览器宽度判断布局。
- 产品信息架构遵循已提供的 Fresnica 原稿：先展示页面上下文，每个路由聚焦一个主要任务，其次展示辅助内容，最后使用统一的五项底部导航。
- 该外壳仅用于 Demo，不作为组件库公开导出，也不能借此增加新的钱包字段或产品能力。空状态和错误状态作为通用组件记录在设计系统入口，钱包中的具体用法仍放在示例入口。
