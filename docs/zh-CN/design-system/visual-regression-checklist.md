# 视觉回归检查清单

这份清单是 Fresnica UI 的人工视觉基线。Token 审计检查的是契约，这份清单检查的是这些契约组合到界面后是否正确呈现。

## 检查设置

- 检查视口矩阵：320px、360px、390–393px（393px 主检查、390px 兼容检查）、430px、768px 和实际桌面宽度。统一使用 CSS 视口像素，不使用设备物理像素。
- 主题：浅色和深色分别完整检查。
- 浏览器：最新 Chromium，或项目实际支持的浏览器范围。
- 状态：组件支持时分别检查默认、悬浮/焦点、选中、禁用、加载和错误状态。
- 网络：示例和钱包流程只使用 Stellar 术语。
- 钱包示例：Fresnica 钱包流程继续放在固定 390 × 844 的移动端预览框中，将其视为移动端大屏示例，再按矩阵宽度复核响应式布局；需要滚动预览框内部查看首屏以下内容。
- 组件组合：使用 Layout 页面内置的宽度切换器，检查同一套通用组合在 320px、360px、393px、430px、768px 和桌面宽度下的变化。
- 浏览器缩放到 200% 或使用等效大字号设置时，检查标题、长地址、金额、弹窗、表单和导航能够重排，不发生裁切或横向溢出。设计系统入口按 Web 界面验收，钱包入口仍是独立产品示例。

## 钱包流程页面

在移动端宽度下分别检查两种主题：

- `/fresnica-home`
- `/fresnica-swap`
- `/fresnica-transfer`
- `/fresnica-activity`
- `/fresnica-settings`
- `/fresnica-transaction-details`
- `/fresnica-asset-details`
- `/fresnica-network-nodes`
- `/fresnica-explore-dapps`
- `/fresnica-scan`

每个页面检查：

- 页面顶部标题是普通语义文字，使用主题默认文字色；没有飘带、插画或装饰横幅。
- 主操作使用正确主题主色（浅色 `#00A875`、深色 `#00CA8A`），绿色实心背景上的文字和图标为白色。
- 单个页面或操作区域最多保留一个大面积实心主色重点；钱包首页 Send / Swap / Receive 快捷操作组是已批准例外。
- 普通图标、资产符号占位、复制、Max/All、方向切换、帮助文字和预计数值使用中性 Token。
- 钱包首页余额卡片使用当前主题的中性表面，不增加装饰描边、绿色渐变或钱包地址底色。
- 底部导航当前项使用主绿色图标与文字，背景保持透明，不增加绿色选中容器。
- Swap 保留反色设计：浅色主题黑色，深色主题白色。
- 金融语义保持独立：品牌、成功、交易/请求失败、表单校验错误、上涨、下跌、警告和高风险不能因色值相近而合并。
- 表面使用适配主题的 Token、清晰描边且不使用层级投影。
- Lucide 图标使用正确语义色；可操作控件的目标尺寸尽量不低于 44px。
- Stellar 长地址、余额和交易状态不被截断，也不产生横向溢出。

## 组件状态检查

- Button：主按钮、次要按钮、反色 Swap、危险、禁用、加载和纯图标状态。
- AddressField、AmountField：复制、粘贴和 Max/All 操作保持中性；语义校验状态保留各自颜色。
- Select、DatePicker、TimePicker：弹出菜单、已选项、键盘焦点和深色表面。
- Checkbox、Radio、Switch：选中/未选中、禁用和深色描边。
- Modal、Drawer、Notification：浅色/深色表面、语义图标色、焦点恢复和关闭操作。
- Progress、Skeleton：Token 配色、文字可读性，以及失败或禁用状态不误用绿色。
- Tabs、Table、Pagination、BackTop：选中、禁用、交替行和深色状态。
- Image、Carousel：图片失败回退、加载状态、预览关闭操作和批准的素材比例。

## 自定义主题检查

- 分别从设计系统首页、组件文档页和钱包示例页打开主题色入口。
- 输入有效的六位 HEX 颜色，确认浅色和深色模式下的品牌色与交互色都会更新。
- 分别尝试很浅、很深和高饱和度的颜色，确认主操作文字和图标仍满足 WCAG AA 可读性。
- 如果发生调整，确认行内提示说明系统为了保证文字和图标清晰可见而调整，并显示实际采用的 HEX 色值，同时 HEX 输入框仍保留用户输入值。
- 输入无效 HEX 值，确认当前有效主题不会被破坏，失焦后输入框恢复为上一个有效值。
- 确认成功、失败、上涨、下跌、警告和高风险颜色仍与自动生成的品牌色保持区分。
- 刷新页面并打开第二个标签页修改主题，确认本地持久化和多标签页同步都生效。
- 点击“恢复默认”，确认 Fresnica 原始浅色/深色 Token 恢复，且其他语义颜色不被改变。
