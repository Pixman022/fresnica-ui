# 平台适配层

平台适配层说明共享核心如何在移动端、Web 和桌面客户端中落地。它可以改变布局和输入方式，但必须保持相同的语义 Token 和任务层级。

## 移动端

- 内容需要时，在响应式过渡点以下使用单栏布局。
- 使用移动端顶部栏承载标题、返回和页面级操作。
- 底部导航只用于移动端一级目的地；需要安全区适配，设计要求透明时不增加选中背景容器。
- 在可行情况下，交互目标不小于 44 CSS px。
- 处理系统键盘、长地址和大金额，不能产生横向裁切。
- 聚焦任务使用底部面板或弹窗，并提供明确的关闭或取消路径。
- 检查 320、360、390–393、430px 预设，以及 768px 平板过渡。

## Web

- 一级导航使用顶部导航或侧边栏；不能默认把移动端底部导航作为 Web 外壳。
- 同时提供鼠标悬停和键盘 `:focus-visible` 状态，不能只依赖悬停提示。
- 保持合理的 Tab 顺序，并确保浏览器缩放到 200% 时内容不被裁切。
- 使用可通过 URL/深链接访问的路由，并保留浏览器前进/后退行为。
- 在有助于发现性或信息密度时，使用气泡、菜单、Tooltip 和宽屏表格。

## 桌面客户端

- 支持可调整的内容区域，并记录可用的最小窗口宽度。
- 需要对比信息时，优先使用侧栏 + 内容区或多栏布局。
- 区分悬停、键盘焦点和按压状态。
- 只有稳定且高频的操作才定义键盘快捷键。
- 只有桌面产品确认需要时，才使用右键菜单和命令面板。
- 窗口标题栏、系统托盘、最小化和调整窗口行为属于桌面壳层，不属于共享组件库。

## 共享映射规则

| 关注点 | 跨平台核心 | 平台适配层 |
| --- | --- | --- |
| 一级导航 | 当前目的地明确且可访问 | 移动端底部导航；Web 顶部/侧边导航；桌面侧栏 |
| 聚焦任务 | 有明确进入、完成和取消路径 | 移动端底部面板；Web 弹窗/气泡；桌面弹窗或侧栏 |
| 信息密度 | 金额、状态和标签保持可读 | 单栏；响应式表格；桌面多栏视图 |
| 主题 | 语义 Token 和对比度要求 | CSS 变量、原生资源或桌面主题桥接 |

## 平台术语

项目统一使用“移动端”“移动端视口”和“移动端底部导航”。只有记录平台专属接入或引用来源时才提及 iOS 或 Android；设计系统本身不绑定操作系统。
