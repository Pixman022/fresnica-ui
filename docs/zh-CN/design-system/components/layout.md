# 布局与结构组件规范

Fresnica 布局组件统一使用中性表面、清晰描边与语义色 Token，不使用层级投影。正式产品页面不得加入场景插画、飘带、纹理图案或游戏化装饰动画。

## Footer 页脚

页脚只显示文字。普通页面使用 `default`，信息密集的移动端页面使用 `compact`。

## Card 卡片

源码：`src/components/Card`。

- 默认卡片使用 `--Fresnica-surface`、低对比度 Token 边框和 24px 大圆角 Token。
- `type="dashed"` 仅用于添加、导入和空状态入口。
- 只有整张卡片可点击时才启用 `hoverable`。悬浮时边框切换为主色并上移 2px；虚线卡片不发生位移。
- `color` 用于简短的语义提示，不用于大面积页面容器。使用 Demo 中记录的语义角色；金融角色（成功、失败、上涨、下跌、警告和高风险）与品牌色、协议辅助色保持独立。
- 旧颜色别名继续兼容，但统一映射到相同的语义 Token，不增加额外色相或仅适用于浅色主题的表面。

```tsx
<Card>账户摘要</Card>
<Card type="dashed" hoverable>添加账户</Card>
<Card color="purple">协议提示</Card>
```

## 响应式组件组合预览

Layout Demo 增加了仅用于 Demo 的屏幕宽度切换器，可在 `320px`、`360px`、`393px`、`430px`、`768px` 和当前桌面可用宽度之间预览同一套通用组件组合。

- 切换的是预览容器宽度，不改变浏览器窗口、设计 Token 或组件库公共 API。
- 宽度菜单会附带中性的场景标签（小屏移动端、常见移动端、大屏移动端、超大屏移动端、平板竖屏或当前浏览器窗口）；这些标签仅作参考，不代表与某一款设备一一对应。
- 选中档位后会在下方显示一行设备参考说明，仅用于帮助理解尺寸，不构成设备兼容性承诺。
- Layout 页面在桌面端使用 `1200px` 最大内容宽度，使组件组合能够展示多列行为，同时避免内容铺满整个窗口而降低可读性；其他组件页面保持原有阅读宽度。
- 在紧凑宽度下，表单变为单列，操作区允许换行，辅助文字允许重排。
- 在较宽的视口下，表单与信息列表可以并排，间距/圆角/控件高度示例仍限制在预览容器内。
- 该预览用于比较不同宽度下的布局关系，不是具体设备模拟器，也不能替代产品页面的视觉验收。
- 切换器仅属于设计系统 Demo，不会影响钱包示例页面。
- 打开 Demo 中的“显示尺寸标注”后，可查看当前组合使用的字号、图标尺寸和触控区域基线。标注仅用于验收辅助，不属于运行时组件 API。

## TransactionDetails 交易详情

用于展示交易摘要、状态、Stellar 字段和可选的区块浏览器入口。协议相关数据通过 `fields` 传入；浅色和深色模式均使用语义表面与文字 Token。

## Title 字体

`Title` 是使用 Roboto / Noto Sans SC 字体栈的纯语义文字，不带容器、飘带、渐变或装饰。

| 尺寸 | 使用场景 | 字号 / 字重 |
| --- | --- | --- |
| `large` | 页面标题 | 28px / 700 |
| `middle` | 区块标题 | 18px / 700 |
| `small` | 分组标题 | 14px / 700 |

应按文档层级选择 `as="h1"` 至 `as="h4"`，不要仅按视觉大小选择。默认文字使用 `--Fresnica-text-color`；只有标题本身具有明确语义时才使用颜色变体。

```tsx
<Title as="h1" size="large">活动</Title>
<Title as="h2" size="middle">资产</Title>
```

## Carousel 轮播

源码：`src/components/Carousel`。

轮播仅用于少量产品公告或引导页。组件使用中性表面、Lucide 导航图标和主色状态指示器；财务数据和交易状态禁止自动轮播。

- 左右箭头为 42px 圆形控件，使用 Lucide `ChevronLeft` 与 `ChevronRight`。
- 指示器点击区域不小于 30px，当前项显示为 24px 主色短条。
- 默认关闭自动播放；指针悬浮或键盘聚焦时暂停。
- 支持方向键、Home、End；系统开启“减少动态效果”后取消过渡。

## Divider 分隔线

分隔线是基于 Token 的 1px 线条，提供 `subtle`、`solid`、`dashed`、`accent` 四种样式。默认使用 `subtle`；`accent` 仅用于区分重要的钱包操作或摘要。

## Collapse 折叠面板

源码：`src/components/Collapse`。

用于高级交易信息、网络说明和帮助内容。表面、边框、文字及焦点状态全部使用 Fresnica Token。前置 Plus 与后置 ChevronDown 均来自 Lucide；展开旋转只用于表达状态，不属于装饰动画。

- 标题点击区域满足移动端触控需求。
- 展开内容通过 `aria-controls` 与 `aria-labelledby` 建立关联。
- 禁用项降低透明度且不可交互。

## Tabs 标签页

源码：`src/components/Tabs`。

标签页使用 `--Fresnica-surface` 容器；当前项为主色实心胶囊，文字保持白色。悬浮使用 `--Fresnica-primary-color-bg`，键盘焦点使用 `--Fresnica-focus-color`。容器与 Tab 列表跟随当前主题，不能写死白色背景。

- 建议容纳 2–5 个同级视图，例如“资产 / 活动”或“发送 / 接收”。
- 标签名称应简短，不使用装饰 Emoji 或游戏化状态标记。
- 小圆点仅作为选中指示，不作为插画元素。
- 支持方向键、Home、End 切换焦点与选中项。

所有主色实心背景上的文字和图标都必须通过 `--Fresnica-on-primary-color` 保持白色。

## BalanceCard 余额卡片

BalanceCard 是主色实心的余额摘要变体，支持法币值、次级数值、涨跌幅和隐私隐藏，并计入页面唯一的大面积主色重点；仅在产品层级明确要求时使用。当前钱包首页示例改用中性卡片：浅色模式使用 `--Fresnica-surface`，深色模式使用 `--Fresnica-surface-high`，不增加装饰描边或渐变。主色实心 BalanceCard 中的下跌变化使用下跌语义容器组合，不直接把原始下跌色放在绿色背景上。

## WalletSwitcher 钱包切换器

显示当前钱包、缩略地址和可选头像的紧凑账户选择器。仅用于切换本地 Stellar 账户，不用于切换区块链网络。

## QuickAction 快捷操作

用于发送、接收、兑换和扫码的移动端快捷入口。只传入 Lucide 图标；图标和标签构成同一个按钮，触控区域不小于 44px。默认使用中性样式；只有产品层级明确要求时才使用 primary 或 inverse。钱包首页 Send / Swap / Receive 组合是保留既有配色的已批准例外。

## BottomNavigation 底部导航

正式产品的移动端一级导航。使用 Fresnica 产品确定的导航名称和 Lucide 图标；导航固定在移动端画布底部，不使用装饰性外框描边。当前项的图标和文字使用语义主色，背景保持透明，并设置 `aria-current="page"`。柔和主色背景仅用于悬浮状态，键盘焦点仍通过焦点描边清晰呈现。

## AssetIcon 资产图标

优先显示传入的资产图片；无图片时回退为简短的大写资产符号。用于 Stellar 资产，并在同一列表中保持尺寸一致。资产符号占位默认使用中性文字色；只有颜色能够识别协议或发行方时才使用对应语义色，不能作为通用装饰。

## AssetRow 资产行

单条可选资产摘要，包含 `AssetIcon`、余额、法币价值和可选涨跌幅。只有真实变化才使用上涨/下跌 Token，预计数值和普通余额保持中性。整行可作为交互入口；选中态可以使用克制的主色浅底，但不能把整行文字都强制变成主绿色。

## TransactionRow 交易行

用于活动列表的紧凑交易条目。方向图标使用 Lucide；状态文字使用语义容器组合，且不能只靠颜色传达含义。成功使用 `success`，失败使用 `failure`，待处理使用 `warning`。

## TransactionStatus 交易状态

用于 `pending`、`success`、`failed` 的状态标签。状态标记旁必须始终显示可读文字，并使用对应的 `*-color-bg` 与 `on-*-container-color` 组合，确保 11px 标签在两种主题下清晰可读。

## NetworkBadge 网络标识

显示 Stellar 网络及连接状态（`online`、`degraded`、`offline`）。在线使用成功 Token，降级使用警告 Token，离线使用失败 Token；品牌主色不能替代连接状态语义。Fresnica 当前仅支持 Stellar，文案不得暗示支持其他链。

## SwapRoute 兑换路径

显示选中的 Stellar 兑换路径、可选中间资产、汇率和最优路径状态。方向箭头使用 Lucide，路径强调保持信息性，不做营销化装饰。
