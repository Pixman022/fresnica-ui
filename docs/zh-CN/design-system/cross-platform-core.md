# 跨平台核心

跨平台核心定义 Fresnica UI 在移动端、Web 和桌面客户端之间必须保持一致的部分。它描述语义、层级和状态，不强制规定某个平台的导航形式或交互手势。

## 作用

- 保持品牌、语义颜色、字体层级和状态语言一致。
- 为组件状态和可访问性提供统一词汇。
- 将钱包示例与可复用的设计系统契约分开。
- 允许不同平台根据输入方式选择合适的交互形式。

## 设计原则

- 清晰优先：内容和任务层级始终可见。
- 内容克制：主题服务于任务，不抢夺金融信息的注意力。
- 状态明确：加载、空、成功、警告和错误状态不能只依赖颜色区分。
- 可恢复：失败或危险操作提供明确的下一步。
- 语义一致：同一个 Token 名称在所有平台表达同一个意图。

## 共享基础

所有平台共享以下内容：

- 表面、文字、边框、操作和状态色的语义 Token。
- 浅色/深色主题和本地自定义主题色生成。
- 字体层级、间距、圆角、动效和层级 Token。
- 默认、悬停/按压、焦点、选中、禁用、加载、空和错误状态。
- WCAG AA 对比度、适用平台的键盘焦点、减少动效和非颜色状态提示。
- 金额、长地址、时间和交易状态的可读性规则。

使用 `color.surface.primary`、`color.text.primary`、`color.action.primary` 等语义名称；由平台适配层将这些名称映射到 CSS、原生或桌面实现值。

## 响应式基线

预览和 Web 界面统一使用 CSS 视口像素：

| 预设 | 宽度 | 用途 |
| --- | ---: | --- |
| 移动端小屏 | 320px | 最紧凑布局和溢出检查 |
| 移动端常见 | 360px | 常见 Android 视口 |
| 移动端大屏 | 390–393px | 主要移动端视觉基线；393px 主检查、390px 兼容检查 |
| 移动端宽屏 | 430px | 更宽手机的间距和信息密度 |
| 平板 | 768px | 平板过渡和多栏布局判断 |
| Web/桌面 | 实际窗口宽度 | 容器、导航和信息密度检查 |

这些是验收预设，不是按设备型号编写的 CSS 分支。优先使用流式尺寸、最大宽度容器和由内容决定的断点。

## 范围边界

核心规范包含组件契约、状态、Token、可访问性和布局原则。钱包产品的信息架构继续放在 `examples.html` 及其产品文档中，不作为可复用设计系统核心的必需章节。

Apple Human Interface Guidelines、Material Design 和 Web 可访问性规范都是参考来源，项目仍统一使用跨平台术语。
