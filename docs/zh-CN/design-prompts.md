# 设计提示词

将下面的简要说明交给 UI 生成工具；精确数值仍以[设计系统](./design-system/README.md)为准。

```text
为 Stellar 网络设计 Fresnica 移动钱包界面。

视觉方向：
- 简约、精确的金融科技风格，搭配柔和圆角中性表面。
- 拉丁文字和数字使用 Roboto，中文回退为 Noto Sans SC。
- 浅色主色 #00A875，深色主色 #00CA8A；绿色实心控件始终使用白色文字。
- 保持品牌绿稀缺：单个页面或操作区域只保留一个大面积实心主色重点；普通图标、元数据、复制、Max/All、方向切换和预计数值使用中性色。
- 品牌、成功和上涨即使都呈绿色也必须保持独立；完成/健康状态使用成功色，只有真实金融正向变化使用上涨色。
- 底部导航当前项使用主绿色图标和文字，背景保持透明。
- Swap 主要操作使用 inverse Token：浅色主题黑色，深色主题白色。
- 语义辅助色仅使用协议紫、网络蓝、流动性橙和待处理黄。
- 界面图标只使用 Lucide；品牌标志仅限已批准的 Fresnica Logo 与应用图标。
- 控件圆角 8–16px，卡片圆角 16–24px；通过细边框和表面色差建立层级，不使用投影。
- 动效时长保持在 0.15–0.35s，并支持 reduced-motion。
- 内容围绕 Stellar 资产、Horizon 网络状态、签名、手续费、转账与兑换。
- 避免自然主题插画、异形装饰、纹理背景和游戏化效果。
```

若生成代码，必须使用语义 `--Fresnica-*` CSS 变量，并在 320px、360px、390–393px、430px 移动宽度，以及 768px 和桌面宽度下验证亮/暗主题。
