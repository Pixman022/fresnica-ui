# Fresnica 官网动画工作计划 — Motion M3 — 2026-10-26

## 背景

Motion M2 已在主分支完成并通过视觉复核。当前指针视差、视口感知环境动画、标签页隐藏暂停、Reduced Motion、CI 与 GitHub Pages 均处于正常状态。

M3 只增加“状态切换微动效”，不新增持续环境动画、不做滚动联动、不启动移动端重设计，也不修改任何产品声明。

## M3 — 本轮直接实现

1. **中英文切换淡入淡出**
   - 浏览器支持时使用原生 View Transitions API。
   - 过渡保持短促、克制，不做明显位移。
   - 不支持的浏览器继续使用现有即时切换。
   - 如果用户通过语言按钮触发切换，切换后恢复语言按钮键盘焦点。

2. **FAQ 展开细化**
   - 保留现有网格行展开/收起逻辑。
   - FAQ 正文加入很小的淡入与纵向位移，减少内容突然出现的感觉。
   - 不改变现有 ARIA 状态和交互逻辑。

3. **CTA 方向反馈**
   - Hero 按钮现有箭头在 hover / focus 时仅移动数像素。
   - 不改变按钮尺寸、文案、路由或下载状态。

4. **无障碍 / 性能**
   - `prefers-reduced-motion: reduce` 下关闭所有 M3 新增动效。
   - 只使用 opacity 与 transform。
   - M3 不新增滚动监听或新的持续动画。

## 继续延后

- 跨区块轨道贯穿；
- 滚动联动几何动画；
- Hero 以外的指针效果；
- Features 内更丰富的持续动画。

这些项目继续延后，因为它们会明显增加页面的动态密度。

## 完成标准

- 支持和不支持 View Transitions 的浏览器都可以正常切换语言。
- 通过语言按钮切换后，键盘焦点可以回到语言按钮。
- FAQ 的 ARIA 状态保持正确。
- Reduced Motion 下不存在 M3 新增动画。
- 不改变布局、信息架构、产品、安全、下载或发布状态声明。
- CI、文档同步、Demo build、Delivery artifact、视觉 QA 与 GitHub Pages 全部通过。
