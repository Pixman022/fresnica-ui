# Fresnica 官网预发布事实核验 — 2026-10-26

## 核验范围

本次核验覆盖 `public/fresnica-website-preview/index.html` 中已部署的 Fresnica 官网预览。
检查内容包括产品定位声明、发布/下载状态、安全相关措辞、法律/联系方式占位状态以及旧路由兼容行为。
当前视觉基线仍为 **Geometric Light V2.4**。

## 已确认 / 有依据的产品定位

当前官网预览与已确认的产品方向一致：

- Fresnica 被明确描述为专注 **Stellar** 生态的钱包，而不是多链钱包。
- 产品方向覆盖 **XLM**、受支持的 Stellar 发行资产、转账与收款、Swap，以及兼容的 Stellar 应用。
- iOS 与 Android 均描述为**计划支持**。
- 产品明确标注为**开发中**。
- 官网仅承担信息介绍作用；实际钱包操作被描述为在移动 App 中完成。
- 官网展示的产品 UI 已标明为示意/演示内容。

## 当前明确不作出的声明

在完成核实前，官网不会声明以下内容：

- 非托管 / 自托管属性；
- 加密或密钥存储实现细节；
- 开源状态；
- 当前已在 App Store 或 Google Play 上架；
- 已确认的发布日期；
- Stellar 官方背书或正式合作关系；
- 已核实的联系方式或社区渠道；
- 已发布的隐私政策或服务条款。

- 当前不存在 App Store、Google Play 或其他官方分发地址。
- iOS 与 Android 均标记为尚未开放。
- Download 区域明确说明，只有在确认后才会加入已核实的官方分发链接。
- 本次核验已收紧 FAQ 第 4 项，直接回答当前状态：**Fresnica 目前尚未开放下载。**

## 安全措辞保护措施

官网目前仅保留以“核对与理解”为核心的安全提示：

- 核对支付详情；
- 理解应用请求；
- 仅使用已核实的下载入口；
- 不要在声称提供下载的网站中输入秘密恢复信息。

密钥管理、恢复机制、托管模式以及具体安全控制的实现细节，仍需在正式产品/安全资料核实后再公开。

## 法律与联系方式状态

Footer 与 Help 区域明确说明：经核实的官方渠道与政策会在就绪后公布。
当前没有将任何占位邮箱、社交账号、隐私政策 URL 或服务条款 URL 伪装成已生效入口。

## 旧路由兼容行为

旧 hash 路由会被映射到当前单页网站：

- `#features`
- `#download`
- `#about`
- `#help`
- `#help/security`
- 中文版本使用 `#zh/...`

旧版多页面原型内容不会通过当前 `render()` 路径渲染。

## 正式发布前仍需确认的阻塞项

在真正公开发布前，需要提供并独立核实以下信息：

1. iOS 官方分发 URL；
2. Android 官方分发 URL；
3. 已确认的发布时间 / 发布状态；
4. 隐私政策；
5. 如发布要求需要，提供服务条款；
6. 已核实的项目联系方式 / 社区渠道；
7. 关于密钥管理、恢复机制及托管/安全控制的正式产品安全措辞；
8. 如存在 Stellar 正式合作或背书，只能在完成核实后披露。

在这些事实就绪前，应继续保留当前预发布措辞。
