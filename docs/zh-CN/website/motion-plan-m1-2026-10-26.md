# Fresnica 官网动画工作计划 — Motion M1 — 2026-10-26

## 目标

在已经冻结的 **Geometric Light V2.4** 官网基础上增加克制的动画效果，同时不改变产品声明、信息架构、下载状态和现有浅色几何视觉体系。

动画的作用是让页面更有生命力，而不是让动画本身成为主角；手机产品 UI 仍然只作为必要的产品展示元素。

## 原则

- 优先使用 `transform` 与 `opacity`，避免高开销布局动画、大面积动态模糊、WebGL 和重 3D。
- 持续动画保持缓慢、环境化。
- 主题绿色仍只用于视觉焦点，动画不能增加绿色密度。
- 动画不能造成“正在加载”“已经可下载”或“实时钱包数据”的误导。
- 完整支持 `prefers-reduced-motion: reduce`，关闭动画后内容与交互仍可正常使用。
- M1 不启动移动端重设计；持续环境动画以桌面/平板为主。

## M1 — 本轮直接实现

1. **Hero 入场**
   - 首次进入页面时，Hero 文案与主视觉轻微淡入上移。
   - 位移保持很小，使用自然减速曲线。

2. **Hero 环境几何动画**
   - 两条抽象轨道进行非常缓慢的旋转。
   - 手机模型加入极轻微上下浮动。
   - 手机必须保持足够稳定，不能影响阅读。

3. **Features**
   - 区块标题与四张功能卡进入视口时只播放一次入场动画。
   - 四张卡片做轻微错峰。
   - Hover 仅上浮约 3–4px，并加入少量与功能语义相关的微动效。

4. **Security**
   - 两层轨道缓慢反向旋转。
   - 文案与几何图形进入视口时播放一次入场。
   - 中心锁保持稳定，不旋转。

5. **FAQ**
   - 展开/收起使用短时的网格行过渡。
   - 视觉状态与 ARIA 状态保持同步。

6. **无障碍 / 性能**
   - 系统开启减少动态效果后，关闭持续动画与过渡。
   - 入场动画只使用一个共享 IntersectionObserver。
   - M1 不加入滚动驱动的 JavaScript 动画。

## 延后到 M2

- 鼠标 / 指针视差；
- 跨区块轨道贯穿；
- 滚动联动几何动画；
- 中英文切换淡入淡出；
- 更丰富的单项功能语义动画。

以上内容等待 M1 在真实浏览器完成视觉验收后再决定。

## 完成标准

- 不改变页面布局结构与信息架构。
- 不新增产品、安全或下载能力声明。
- 不加入真实下载链接。
- 动画不能阻碍阅读和交互。
- Reduced Motion 模式不存在持续动画。
- 现有 CI、文档同步、Demo build、Delivery artifact 全部通过。
- GitHub Pages 部署成功。
