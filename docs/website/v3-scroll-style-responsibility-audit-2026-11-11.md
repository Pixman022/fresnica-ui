## 2. CSS 层叠分类

参考此前 `v3-quality-stabilization-plan-2026-11-09.md` 的静态候选清单；其中重复选择器不是已确认的视觉故障。

| 区域 | 已核实的多层规则 | 当前处理 |
| --- | --- | --- |
| 顶部中间导航 | `m29-polish.css` 固定桌面 340px、窄屏 210px/184px；`index.html` 后续 m47 负责 44px 热区、窄屏高度和 gap；按钮语义层又负责颜色与焦点 | 规则分别属于宽度约束、交互尺寸、主题，不整合 |
| 返回顶部 | 早期 m16 负责位置和小屏避让，m23 负责悬停展开，m53/55 调整中性配色和圆形/胶囊边角 | 保留多层职责，避免破坏第五屏移动端遮挡回避 |
| 第五屏桌面示例 | `index.html` 管理 16:9 位置及窄高视口；`m50-desktop-preview.css` 管理四模块内容与分段响应式；深色规则覆盖语义色 | 保留 1100px/800px/680px 等适配差异，若出现截图偏差再定位具体选择器 |
| 首屏移动版 | m10 的流程式布局与 M57 的 <=480px 留白优化同为有意适配 | 本次仅记录，没有新的 CSS 修改 |

**结论**：当前没有证据证明直接删除这些同名选择器会改善用户体验，先以已有 7 视口 × 2 主题、原生 200% 缩放、九屏正常与减少动态回归保障现状。若发生新问题，先记录实际生效属性、媒体条件、视口、语言、主题和截图，再针对真实冲突修改。

## 3. 待验收与限制

1. **真实 GPU/功耗**：Windows 显卡浏览器、macOS Safari、iOS Safari、Android Chrome 均需基于物理设备测量；自动化 RAF 次数不等于 GPU FPS。
2. **设计签收**：自动化回归不能替代九屏双语深浅主题的设计负责人逐屏检查。
3. **发布事实**：官方安装地址、法律政策和安全能力声明未获核实，维持预览站 `noindex`、下载禁用状态。

正式性能验收模板仍为 [`v3-device-performance-acceptance-2026-11-09.md`](v3-device-performance-acceptance-2026-11-09.md)。
