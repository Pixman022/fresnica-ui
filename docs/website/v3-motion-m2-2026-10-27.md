# Fresnica V3 — M2 scroll motion refinement

Date: 2026-10-27

## Scope and guardrails

- Work is limited to the V3 prototype at `public/fresnica-v3-motion-preview/index.html` on `design/website-vision-motion-concept-2026-10-27`.
- The previous M1 layout, copy, information architecture, and the approved Hero orb shader/markup remain in place. The Hero's first JavaScript block was byte-for-byte unchanged during M2.
- `main`, the archived V2 baseline, and the deployed live preview must not be changed.
- Source of timing: user-provided ~94-second reference video; 0–15 s for sparse storytelling and dark contrast, 18–33 s for the horizontal feature cards, and 81–93 s for the particle wordmark and theme change.

## Implemented

1. **Horizontal feature reel:** a measured scroll rail with proportional desktop travel, 13% entry and 13% exit holds, smoothstep interpolation, responsive overflow, a synced 01–05 indicator, and card stepping that targets the inverse easing coordinate. Mobile and reduced-motion users retain scrollable cards without a pinned effect.
2. **Particle storytelling:** the sparse 78-point ecosystem scene now spreads and contracts with scroll position, retaining the earlier minimalist particle layout.
3. **Dark contrast:** three independent headline lines enter in sequence as the scene reaches the viewport. The original copy and two comparison cards stay unchanged.
4. **Workspace:** the mock dashboard scales/settles subtly and the green connection line draws as the scene enters, with the illustration still marked not-live data.
5. **Real footer particles:** the wordmark is sampled with local 2D canvas and assembled from dots; the Fresnica green wave appears as the footer enters, with a subtle time-based shimmer. The original CSS dot-word remains an accessible visual fallback when canvas is unavailable and under reduced-motion preference.
6. **Performance/accessibility:** motion updates run in a scroll-throttled animation frame; footer rendering is visibility-gated and limited to ~30 fps; the theme toggle, page navigation, FAQ, keyboard/menu behavior and reduced-motion support are retained.

- Rail measurements at 1440×900: scroll travel 954 px; horizontal overflow 494 px; leading/trailing holds at 0 and −494 px; midpoint at −247 px; final state 05 / 05.
- Canvas footer: 1,264×290 drawing buffer; real nontransparent sampled pixel data; a delayed frame differs from an earlier frame after scrolling to the final section.
- Reduced Motion: pinned horizontal translate disabled, CSS wordmark visible and footer canvas hidden.
- Comparison confirms the original Hero orbital script, HTML `<canvas id="orb-canvas">` and `<div class="orb-field">` remain unchanged.
- QA test and screenshot montage are included in the conversation deliverables; browser verification used the local self-contained HTML file.
