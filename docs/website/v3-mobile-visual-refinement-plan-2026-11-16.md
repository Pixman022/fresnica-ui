# Fresnica V3 · 移动端视觉调整计划（2026-11-16）

## 基线与范围
- 基于本次移动端长截图及 V3 最新源码；目标是改善前五屏的视觉层级、清晰度和可读性。
- 修改仅适用于视口宽度 **≤680px**；桌面端（≥681px）视觉与动画保持原状。
- 保留九屏顺序、英文/中文切换、浅/深主题、移动端静态粒子实现。
- **不得增加、删减粒子数量**；手机端球体仍为 980 点、第二屏 136 点，底部与安全盾牌的既有采样密度不变；也不恢复移动端 WebGL 或持续动画。
- 不改产品事实、下载可用性、按钮可点击状态及 SEO 配置。

## 优先级和实施
| 等级 | 范围 | 修改 | 验收重点 |
| --- | --- | --- | --- |
| P0 | 第二屏粒子视觉 | 放大移动端静态点阵的分布半径约 20%，提升中心绿点与周围点云的可见性，收紧文字与粒子之间的视觉距离 | 粒子完整可见；上下两组标题不碰撞；粒子数和静态渲染不变 |
| P0 | 第五屏桌面示例 | 小屏采用更高的窗口宽高比；收紧左侧导航占宽，以图标导航让主内容更可读；优化余额、曲线、功能键、资产行的字号和间距 | 320/360/393/430px 能显示窗口四个标签及主内容；不裁切最后资产行；切换功能不变 |
| P1 | 首屏球体 | 仅调整移动端浅色主题下的粒子色彩/透明度，不改变大小和点数 | 提升球面边界辨识度；中央白色粒子 Logo 保持可见；深色模式不退化 |
| P1 | 第四屏滑动提示与页面节奏 | 提升滑动提示字号与对比度；适当压缩过大留白；保持一张完整卡片的滑动方式 | 不遮挡卡片和滚动交互；双语可读 |
| P2 | 顶部 Logo | 沿用完整图标 + Fresnica 的版本，将移动端文字微调为 15px，保留 30px 圆形 Logo 和 44px 点击区域 | 320px 下不与右侧菜单重叠；深浅主题均清楚 |

## 验证
1. 核对 CSS 只包含 `max-width:680px` 及更窄的适配规则，桌面原值不变。
2. 核对首页球体与第二屏粒子生成逻辑中的数量、尺寸和静态模式不变。
3. 扩充自动化断言：移动端第二屏分布尺度、首页点数、桌面缩略窗尺寸、品牌可见性与 320px 断点。
4. 浏览器/真机后续复核 320、360、393、430、680px，英文/中文、亮/暗主题及切换四种桌面示例。自动化未执行前标记为待验收。
5. 不在验收前声称视觉设计已正式批准。
