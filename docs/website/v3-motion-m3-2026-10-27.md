3. The footer's Canvas dots make a brief approximately 1.25-second green radial bloom as the theme changes, then settle into the FRESNICA wordmark. Reduced-motion preference disables this pulse.
4. The theme control is offset from the fixed status pill to avoid visual overlap.
5. No product copy, release availability, official download links, or security implementation claims were changed.
