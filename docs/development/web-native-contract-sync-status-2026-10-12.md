## Migration and compatibility

The Web 1.1 changes are additive:

- Existing `FresnicaThemeProvider` usage remains valid.
- `FresnicaUiProvider` is optional.
- Explicit component copy remains highest priority, followed by component `labels`, Provider
  Locale, then the historical component default.
- Existing calls without a Locale Provider retain their historical defaults.
- `Button` and `Input` DOM refs are optional additions.
- Public language packs are imported through `fresnica-ui/locales`.
- No breaking migration is required.

See [build-and-release.md](./build-and-release.md) for artifact generation and migration details and
[../design-system/component-localization.md](../design-system/component-localization.md) for the
Locale/component contract.
